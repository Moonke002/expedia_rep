# SQL RAG travel assistant prompt

Extend Expedia Rep's saved local API hotel workflow with a two-stage SQL RAG assistant. First send the question and the exact `saved_hotels`, `saved_hotel_zips`, and `demo_hotel_nights` schema to the configured backend OpenAI model; ask for one SQLite SELECT only. Validate and execute that proposal on a read-only SQLite connection using an authorizer limited to those tables and a 20-row result cap. Then send the original question, validated query, and returned rows to the model for a grounded answer. Show the question, proposed query, retrieved records, answer, pending state, and failure state in Vue. Multi-night totals exclude checkout and require a stored row for each requested night; missing nights are insufficient data. Keep simulated rates and room counts labeled as course data. Do not expose the key to Vue, access user/booking tables, write to the database, or claim live inventory.
