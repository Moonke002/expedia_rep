Query rules require hotel-ID joins, inclusive check-in/exclusive checkout, and evidence for every requested night.

- The project-root `.env` contains distinct `GEOAPIFY_API_KEY` and `OPEN_AI` values. The provided Geoapify key was verified against ZIP 19014: the live browser lookup returned Concord Township and six nearby API hotels. The backend uses the Geoapify variable only for location/provider requests and explicitly passes `OPEN_AI` to the OpenAI client. `.env` remains Git-ignored.
- The chat UI is a floating corner panel in `frontend/src/components/TravelChat.vue`, available over every app view; its launcher opens the panel and Escape or the close button dismisses it. `frontend/src/api/chat.js` sends `{message, conversation_id?}` to `POST /api/chat`, which returns the reply and query/retrieval evidence. Conversation history restores when the widget opens.
